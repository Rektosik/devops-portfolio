# Лабораторна робота 3 — Власний DevOps-інструментарій

Набір утиліт автоматизації для резервного копіювання, моніторингу сервісів та перевірки коду перед комітом.

## Призначення `set -euo pipefail`

У скриптах оболонки Bash використовується рядок `set -euo pipefail`:

* **`-e` (errexit)** — негайно зупиняє виконання скрипта, якщо будь-яка команда завершилася з ненульовим кодом виходу (помилкою). Без цього прапорця скрипт продовжить роботу після збою, що може призвести до пошкодження даних або створення порожніх архівів.
* **`-u` (nounset)** — трактує звернення до неіснуючої або неініціалізованої змінної як помилку та перериває скрипт. Без цього прапорця друкарська помилка в імені змінної підставить порожній рядок (наприклад, у `rm -rf /$DIR` це призведе до спроби видалення кореневої системи).
* **`-o pipefail`** — встановлює кодом виходу всього конвеєра (`cmd1 | cmd2`) код виходу останньої команди, яка завершилася з помилкою, а не останньої команди в ланцюжку. Без цього помилка в першій команді пайплайну буде проігнорована, якщо друга команда виконається успішно.

## 1. Скрипт резервного копіювання (`backup.sh`)

Архівує вказану директорію у формат `.tar.gz` із міткою часу, веде журнал подій (`backup.log`) та видаляє старі копії, якщо перевищено ліміт зберігання.

**Параметри:**
* `--source <шлях>` — директорія для копіювання (обов'язковий).
* `--dest <шлях>` — директорія для збереження архіву (обов'язковий).
* `--keep <число>` — кількість останніх копій, які потрібно зберігати (за замовчуванням: `5`).
* `--help` — вивести довідку.

**Коди виходу:**
* `0` — успішне створення архіву.
* `1` — невідомий параметр або відсутній обов'язковий аргумент.
* `2` — директорія-джерело не існує.
* `3` — помилка під час створення архіву.

**Приклад запуску та виводу:**
```bash
$ ./backup.sh --source ./data --dest ./backups --keep 3
[2026-11-17 19:30:01] [INFO] Початок резервного копіювання: ./data -> ./backups/backup_20261117_193001.tar.gz
[2026-11-17 19:30:01] [SUCCESS] Архів успішно створено.
